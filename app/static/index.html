    风格描述

    标签只是往这段原文里加词，你也可以直接改。风格词固定以英文下发（官方提示词习惯），切换界面语言不影响它。

    歌词

    模型按音节排旋律：单行过长或段落失衡会唱飘。中文每行 7–13 字、副歌重复句式更稳。段落标记 [Verse] [Chorus] 是模型词表，不随界面语言翻译。

    文本谱面

    这里和乐谱工作台是同一份谱：任何一边改了，另一边看到的就是改后的。生成新歌时模型一写完谱就显示在这里，不用等整首歌结束。

    这里只编辑文本谱面：不放音块图、不做缩放拖动；逐音符精修请去乐谱工作台。

    规划模式

    作为作品名：同一次提交的候选都归到这个作品下，曲库、播放条与派生任务也都用它。
    同一份词与风格，只有种子不同；本机队列逐个跑。
    官方默认
    越大越贴合风格与歌词，官方按模式给默认值
    非自回归求解步数 ode_steps · 越大越细越慢
    只用于曲库里的「换解码器重导」；新歌生成固定用默认解码器，不受这里影响。

    做完你会得到

    • ✓ 一首完整歌曲 — 48kHz 立体声，可下载可循环试听
    • ✓ 一份乐谱 — 在乐谱工作台读谱、检查谱面（不规划模式下没有）
    • ✓ 生成记录 — 用过的参数与耗时都在曲库里，可一键复用
    • ! 整曲一次成型：改谱 = 重新渲染全曲，其余小节波形不保留
    预计耗时— · 队列前 0 个任务 耗时构成 ▾

      怎么改
      
            
        
              
      • 上下拖音块 = 改音高，拖一下就是一格（一个半音）
        • 
              
      • 拖音块右边缘 = 改长短，后面得有休止符腾地方
        • 
              
      • 点一下选中，按 Delete 删音；↑↓ 微调，Shift+↑↓ 一个八度
        • 
              
      • 改错了按 Ctrl+Z 撤回；改完点顶部「改谱重渲染」才会变成音频
        • 
            
      
            
      
              谱面里的记法
              
        
                
      • 人声旋律写在 V: Vocal，伴奏写在 V: Ins
        • 
                
      • 引号里的是和弦标记，例如 "Cmaj7"，只影响伴奏
        • 
                
      • z 是休止符，竖线是小节线，Q: 是速度
        • 
                
      • 官方脚本只认这种原生写法，通用 ABC 会被拒
        • 
              
      
            
      
          
      
          
      
            
      给 AI 的谱面规则
      
            
      把规则和示例直接粘给写 ABC 的 AI 工具；按它产出的谱，音块图能画、每个音都能改。
      
            
      不符合这些规则的谱仍能生成音频，但音块图会画不出来，只能在「文本谱」里改。

      教程：从零到一首歌
      
        
      一条链路走完创作、试听、改谱。卡住了就回这一页，或者重播界面巡览。
      
        
      
          
        
      
      
      

      
      
        
      先听内置示例
      
        
      示例曲正在读取…
      
        
      
          
          
          
        
      
      
      

      
      
        
      01
      写词与风格
      风格决定编曲与音色，歌词决定旋律节奏。
      
        
      
          
      风格 + 歌词语言、流派、乐器、BPM；按段落写词
      
          →
          
      可改乐谱旋律与和弦先落成谱面
      
          →
          
      完整歌曲48kHz 立体声，可试听可下载
      
        
      
        
        
          
      • 点「载入范例」先拿一套能跑的词与风格，再改成自己的。
        • 
          
      • 中文每行 7–13 字，用 [Verse] / [Chorus] 标段落。
        • 
          
      • 「检查结构」会指出空段落、过长行和缺副歌。
        • 
        
      
      
      

      
      
        
      02
      选规划模式
      决定要不要乐谱，以及要不要理会和弦。
      
        
      
          
      模式产出适合
      
          
            
      旋律 + 和弦可编辑乐谱 + 完整歌曲新歌默认，想改谱就选它
      
            
      仅旋律旋律谱 + 完整歌曲换编曲、做翻唱片
      
            
      不规划只有完整歌曲最快出结果，不打算改谱
      
                
        
      
      
      

      
      
        
      03
      试听与迭代
      生成只是开始，下面几件事最常用。
      
        
        
          
      • 试听与下载：任务卡上直接试听；下载得到 FLAC 无损文件。
        • 
          
      • 收藏与 A/B：曲库里选两条有音频的任务，切换 A/B 时播放位置不变。
        • 
          
      • 改谱重渲染：乐谱工作台改完点「改谱重渲染」，整曲按新谱重跑，耗时和生成一首相同。
        • 
          
      • 复用参数：详情里点「复制参数到创作」，风格、歌词、种子、高级参数与设备一起回填。
        • 
          
      • 整页播放页：点右下角「歌词」整页展开，黑胶/歌词/卡拉OK/环形四种形态（见 04 课）。
        • 
        
      
      
      

      
      
        
      04
      整页播放页
      点右下角「歌词」，播放器整页展开。
      
        
      
          
      黑胶唱片随播放旋转，唱臂走到哪唱到哪
      
          →
          
      歌词 / 卡拉OK整页大字滚动 / 逐字点亮
      
          →
          
      环形镜像频谱环 + 中心音频柱、两侧水波
      
        
      
        
        
          
      • 播放页内按 1–4 切换形态，Esc 收起，点任意歌词句跳转。
        • 
          
      • 未播放时底部不占地方；播放中底条中央常驻三句歌词。
        • 
          
      • 刷新不怕：正在播的歌、进度、播放页展开状态都会自动恢复。
        • 
        
      
      
      

      
      
        
      05
      硬件与等待
      本机并发恒为 1，时间都花在自回归生成上。
      
        
        
          
      • 第一次生成会先加载模型，约 1 分钟。
        • 
          
      • 8GB 显卡能跑短歌；显存不足时自动降级到 CPU，会慢很多。
        • 
          
      • 预计耗时按本机实测和歌词篇幅折算，基准任务编号会写在耗时构成里。
        • 
          
      • 生成中可以离开创作页，按 1–5 切换视图，完成后右下角会提示。
        • 
        
      
      
      

      
      
        
      06
      边界与授权
      这些限制来自官方模型与代码，界面无法绕过。
      
        
        
          
      • 没有音色克隆：音色只能用风格词描述，不能上传参考音频。
        • 
          
      • 不支持局部修补：改一个音也要整曲重渲染。
        • 
          
      • 歌曲长度有上限，超出会截断，任务卡上会标「截断」。
        • 
          
      • 模型权重是 CC BY-NC 4.0：非商业使用；分发前先看 README 里的授权说明。
        • 
        
      
      
      
      
      
        
      07
      乐谱工作台
      读谱 → 改谱 → 校验 → 重新渲染。改错了整曲白跑，所以校验放在生成之前。
      
        
        
          
      • 两种改法：音块图点选拖动改音高与长短，文本谱直接改 ABC；两边是同一份谱。
        • 
          
      • 先检查谱面：改完点「检查谱面」，通过后再「改谱重渲染」，不拿坏谱去跑十分钟。
        • 
          
      • 对比与恢复：「对比原谱」看逐处改动；「恢复原谱」丢弃本地改动。
        • 
          
      • 去和弦 / 转纯音乐：做翻唱片用「去和弦」，要纯伴奏点「转纯音乐谱」。
        • 
          
      • 快速调整：右侧可整曲移调、改速度、删段落，改完同样要重新渲染。
        • 
        
      
      
      

      
      
        
      08
      歌曲管理与字幕
      每次生成都是一条带谱系的任务，派生任务挂在原任务上。
      
        
        
          
      • 谱系与版本：改谱重渲染、渲染成歌、重解码都会派生新任务并挂到原任务，详情里能看到版本号与源任务。
        • 
          
      • 候选对比：候选数量选 2–4，同词同风格、不同种子逐个跑，收藏后 A/B 盲听。
        • 
          
      • 回收站：删除只是把产物移进回收站，保留 30 天，误删能在 runs/_trash 里找回来。
        • 
          
      • 字幕导出：播放页展开「字幕」，可导出 SRT 或 LRC（行级 / 逐字），直接拖进剪辑软件。
        • 
        
      
      
      

      
      
        
      09
      启动与界面
      先让服务跑起来，再认识几个全局开关；部署细节看 README。
      
        
        
          
      • 启动与停止：双击 start.bat 起服务（默认端口 9090，可用 set YUE2_PORT=9091 改），stop.bat 停止并释放显存。
        • 
          
      • 快捷键：1–5 切换视图、Ctrl+回车 生成、空格 播放暂停、L 语言、T 主题、Esc 关弹层、? 看全部。
        • 
          
      • 系统页：跑 doctor 自检、看存储与解码器状态、开「生成加速」（只影响下一个任务）。
        • 
          
      • 语言与主题：中英文与深浅色各自记忆；风格描述与 [Verse] 段落标记固定按英文下发。
        •
