创作一首歌

写风格与歌词 → 模型先出可读可改的乐谱 → 渲染 48kHz 立体声完整歌曲。

风格描述

标签只是往这段原文里加词，你也可以直接改。风格词固定以英文下发（官方提示词习惯），切换界面语言不影响它。

歌词

模型按音节排旋律：单行过长或段落失衡会唱飘。中文每行 7–13 字、副歌重复句式更稳。段落标记 [Verse] [Chorus] 是模型词表，不随界面语言翻译。

规划模式

同一份词与风格，只有种子不同；本机队列逐个跑。
官方默认
越大越贴合风格与歌词，官方按模式给默认值
非自回归求解步数 ode_steps · 越大越细越慢
同一份潜变量文件可分别解码对比，不必重新生成。

    怎么改
    
            
      
              
    • 上下拖音块 = 改音高，拖一下就是一格（一个半音）
      • 
              
    • 拖音块右边缘 = 改长短，后面得有休止符腾地方
      • 
              
    • 点一下选中，按 Delete 删音；↑↓ 微调，Shift+↑↓ 一个八度
      • 
              
    • 改错了按 Ctrl+Z 撤回；改完点顶部「改谱重渲染」才会变成音频
      • 
            
    
            
    
              谱面里的记法
              
      
                
    • 人声旋律写在 V: Vocal，伴奏写在 V: Ins
      • 
                
    • 引号里的是和弦标记，例如 "Cmaj7"，只影响伴奏
      • 
                
    • z 是休止符，竖线是小节线，Q: 是速度
      • 
                
    • 官方脚本只认这种原生写法，通用 ABC 会被拒

    教程：从零到一首歌
    
        
    一条链路走完创作、试听、改谱。卡住了就回这一页，或者重播界面巡览。
    
        
    
          
        
    
      
    

      
    
        
    先听内置示例

    01
    写词与风格
    风格决定编曲与音色，歌词决定旋律节奏。
    
        
    
          
    风格 + 歌词语言、流派、乐器、BPM；按段落写词
    
          →
          
    可改乐谱旋律与和弦先落成谱面
    
          →
          
    完整歌曲48kHz 立体声，可试听可下载
    
        
    
        
      
          
    • 点「载入范例」先拿一套能跑的词与风格，再改成自己的。
      • 
          
    • 中文每行 7–13 字，用 [Verse] / [Chorus] 标段落。
      • 
          
    • 「检查结构」会指出空段落、过长行和缺副歌。
      • 
        
    
      
    

      
    
        
    02
    选规划模式
    决定要不要乐谱，以及要不要理会和弦。
    
        
    
          
    模式产出适合
    
          
            
    旋律 + 和弦可编辑乐谱 + 完整歌曲新歌默认，想改谱就选它
    
            
    仅旋律旋律谱 + 完整歌曲换编曲、做翻唱片
    
            
    不规划只有完整歌曲最快出结果，不打算改谱
    
              
        
    
      
    

      
    
        
    03
    试听与迭代
    生成只是开始，后面四件事最常用。
    
        
      
          
    • 试听与下载：任务卡上直接试听；下载得到 FLAC 无损文件。
      • 
          
    • 收藏与 A/B：曲库里选两条有音频的任务，切换 A/B 时播放位置不变。
      • 
          
    • 改谱重渲染：乐谱工作台改完点「改谱重渲染」，整曲按新谱重跑，耗时和生成一首相同。
      • 
          
    • 复用参数：详情里点「复制参数到创作」，风格、歌词、种子、高级参数与设备一起回填。
      • 
        
    
      
    

      
    
        
    04
    硬件与等待
    本机并发恒为 1，时间都花在自回归生成上。
    
        
      
          
    • 第一次生成会先加载模型，约 1 分钟。
      • 
          
    • 8GB 显卡能跑短歌；显存不足时自动降级到 CPU，会慢很多。
      • 
          
    • 预计耗时按本机实测和歌词篇幅折算，基准任务编号会写在耗时构成里。
      • 
          
    • 生成中可以离开创作页，按 1–5 切换视图，完成后右下角会提示。
      • 
        
    
      
    

      
    
        
    05
    边界与授权
    这些限制来自官方模型与代码，界面无法绕过。
    
        
      
          
    • 没有音色克隆：音色只能用风格词描述，不能上传参考音频。
      • 
          
    • 不支持局部修补：改一个音也要整曲重渲染。
      • 
          
    • 歌曲长度有上限，超出会截断，任务卡上会标「截断」。
      • 
          
    • 模型权重是 CC BY-NC 4.0：非商业使用；分发前先看部署文档里的授权说明。
      • 
        
    
      
    
    
    

    
    
    
      
    系统与模型
    模型常驻在独立工作进程里；卸载即结束该进程，显存彻底释放。
